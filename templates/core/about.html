Account Lifecycle & Governance

The Contributor ID Architecture (#####C)

AetherSpace uses an authoritative ID convention and human verification protocol to guarantee workspace integrity.

1

Registration

The user registers with name, username, email, and password. System assigns default role CONTRIBUTOR.

2

ID Generation

A unique 5-digit Contributor ID is automatically generated (e.g. 26457C).

3

Pending Review

The user sees a dedicated Pending Approval screen. Account status is set to PENDING until reviewed.

4

Admin Approval

Managers or Admins approve the account via the Admin Panel. User can now sign in using their Contributor ID + Password.
