PostgreSQL Live Backups

Supabase Managed Physical Backups

Supabase automatically maintains point-in-time recovery (PITR) and daily write-ahead log (WAL) archives on the hosted PostgreSQL cluster. For local development dumps, execute standard CLI operations.

pg_dump -h db.supabase.co -U postgres -d postgres > backup.sql

Restoration Runbook & Step-by-Step Recovery

Step 1: Database Migration & Schema Prep

Run standard migrations to construct schemas: python manage.py migrate

Step 2: Database Restoration

Restore SQL dump into target database: psql -h db.supabase.co -U postgres -d postgres < backup.sql

Step 3: Storage Object Verification

After database recovery, navigate to Storage & Files and click Run Storage Sync Audit to ensure all records match physical objects.
